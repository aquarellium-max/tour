Резиденция 17 — тур 360° (версия с участком)

Состав
  index.html, style.css, app.js, tour-config.js — сайт
  vendor/      — Pannellum (просмотрщик 360°), работает без интернета-CDN
  plans/       — site.jpg (участок), floor1.png, floor2.png (новые планы)
  panos/       — панорамы: 01.jpg…21.jpg — комнаты, ext_A.jpg…ext_M.jpg — улица

Что доложить
  В panos/ уже есть 02, 03, 10, 13, 16, 17 и все уличные A–M.
  Остальные комнаты (01, 04–09, 11, 12, 14, 15, 18–21) возьмите из папки panos
  прошлого проекта — имена те же. Без них точка откроется с сообщением «нет файла».

Публикация (с компьютера)
  1. Распакуйте все архивы в одну папку (папки panos сольются).
  2. Откройте app.netlify.com/drop и перетащите эту папку.
     Если сайт уже есть: Netlify → ваш сайт → Deploys → перетащите папку в окно —
     ссылка останется прежней.

Правка
  tour-config.js: name — подпись, x/y — место точки на плане в %, yaw — куда смотреть
  при открытии (−180…180). Ссылка на конкретную точку: адрес_сайта/#A или #13.
